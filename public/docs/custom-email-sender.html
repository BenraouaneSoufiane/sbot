Set up a custom sender

Send reconciliation alerts from an address on your company’s domain instead of notifications@reconsile.online.

Before you begin

You’ll need access to your domain’s DNS settings and the SMTP or email-provider credentials for the sender address.

1. Choose the sender address

Create a dedicated address such as notifications@yourcompany.com. Using a dedicated sender keeps alert traffic separate from personal inboxes.

2. Authenticate your domain

Add the SPF and DKIM records supplied by your email provider to your DNS. If your domain uses DMARC, make sure the new sender aligns with that policy. DNS verification can take several hours.

3. Configure your email provider

Enable SMTP or an approved sending integration for the address. If your provider supports app passwords, use one instead of your normal account password.

4. Select the sender in Reconsile

  1. Open Connections in the desktop app and choose Gmail.
  2. Under Send from, select Custom sender.
  3. Enter the verified sender address and save the connection.
  4. Run a small test reconciliation and confirm the message arrives without an SPF, DKIM, or DMARC warning.
Prefer the quick setup?

Select notifications@reconsile.online in Connections. No custom-domain configuration is needed.

Never paste your mailbox password into a shared workspace. Use a revocable app password or provider token where available.
