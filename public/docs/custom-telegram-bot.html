Create and connect a custom bot

Use a Telegram bot you control to deliver structured Reconsile alerts to a private chat, group, or channel.

Keep the token private

A bot token grants full control of your bot. Store it like a password and revoke it in @BotFather if it is ever exposed.

1. Create the bot with @BotFather

  1. Open Telegram and start a chat with the verified @BotFather account.
  2. Send /newbot.
  3. Choose a display name, then a unique username that ends in bot.
  4. Copy the HTTP API token that @BotFather returns.

2. Start the destination chat

Bots cannot begin private conversations. Open your new bot and send /start. For a group, add the bot to the group first. For a channel, add it as an administrator with permission to post messages.

3. Connect it to Reconsile

  1. Open Connections → Telegram, or step 3 while creating a check.
  2. Select Custom bot and paste the token.
  3. Enter the numeric chat ID or the destination’s @username.
  4. Save, then run a reconciliation with an exception to verify delivery.
Troubleshooting

If Reconsile cannot find a private username, send the bot /start and retry. Numeric chat IDs are the most reliable option for private chats and groups.

Manage or revoke the token

Return to @BotFather and use /mybots to edit your bot. If the token is compromised, revoke it, then update Reconsile with the replacement.

Bot creation and token behavior follow Telegram’s official BotFather workflow.
