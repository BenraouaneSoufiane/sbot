sbot
Discord notifications

Create and connect a custom bot

Use a Discord bot you control to deliver sbot alerts to a server channel or directly to one person.

Keep the token private

A bot token grants control of your bot. Store it like a password, never commit it, and reset it immediately if it is exposed.

1. Create the Discord app

  1. Open the Discord Developer Portal and select New Application.
  2. Open Bot. Copy the bot token, or select Reset Token to generate one.
  3. For private use without a server, open Installation, enable User Install, add the applications.commands scope, then install the app using its install link.
  4. For a server channel, enable Guild Install with the bot scope and grant View Channels and Send Messages.

2. Get your Discord user ID

Enable Discord Settings → Advanced → Developer Mode, right-click your profile, and select Copy User ID.

sbot creates the private DM automatically. You do not need to call Discord's API or find a DM channel ID yourself.

3. Connect it to sbot

  1. Open Connections → Discord, or step 3 while creating a check.
  2. Select Custom bot and paste the bot token.
  3. Enter the recipient's numeric Discord user ID. sbot will resolve and remember the private DM channel.
  4. Save, then run a reconciliation that produces an exception.
Troubleshooting

Missing Access means the bot cannot reach the destination. Check its channel permissions. Cannot send messages to this user means the user must allow or initiate DMs with the app.

sbot creates a private DM through Discord API v10 and stores its channel ID for future alerts. A webhook URL is not required.
