WhatsApp notifications

Connect a custom WhatsApp bot

Use your own Meta WhatsApp Cloud API credentials to send alerts and let the sbot agent answer inbound messages.

  1. Create or select a WhatsApp Business app in Meta for Developers.
  2. Open Connections → WhatsApp, or step 3 while creating a check.
  3. Select Custom bot, then enter its access token, Phone Number ID, and destination number.
  4. In Meta's WhatsApp configuration, set the callback URL to https://sbot.rest/api/webhooks/whatsapp, enter the server's configured verify token, and subscribe to messages.
Keep the token private.

sbot stores it only in this workspace and never displays it on connection cards.
